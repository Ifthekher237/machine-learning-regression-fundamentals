# Machine Learning Regression Fundamentals

This repository contains my undergraduate honors thesis completed in 2022 during my Bachelor’s degree at the Department of Applied Mathematics, University of Dhaka.

The report focuses on core machine learning concepts, including:

* Supervised and unsupervised learning
* Linear regression
* Logistic regression
* Gradient descent optimization
* Cost functions
* Decision boundaries
* Overfitting and underfitting
* L1 and L2 regularization

The project was written as a mathematical and conceptual review of frequently used machine learning algorithms and their real-world applications.

## Topics Covered

### Machine Learning Fundamentals

* Scope and limitations of machine learning
* Types of ML models
* Classification vs regression

### Linear Regression

* Hypothesis functions
* Cost functions
* Gradient descent
* Model optimization
* Error analysis

### Logistic Regression

* Sigmoid function
* Decision boundaries
* Classification problems
* Logistic cost functions

### Regularization

* Bias-variance tradeoff
* Overfitting vs underfitting
* L1 regularization
* L2 regularization
* L-curve method
